# Build Guide

This file is **hand-maintained** (not generated by CI).

## Repository layout

The repo follows the `repo-i18n` skill layout — see
[`repo-i18n/references/folder-layout.md`](../repo-i18n/references/folder-layout.md).

- **Input** (source of truth, hand-edited):
  - `assets/.i18n_config/i18n.yml` — root README language (`root_lang`, default
    `en`) and the optional `fallback` tree (recursive, empty by default)
  - `assets/bundles/{code}.json` — app UI strings per locale
  - `assets/docs/{code}.json` — README content per locale
  - `assets/templates/README.md` + `i18n.md` — `{{placeholder}}` templates
- **Output** (CI-generated, never hand-edit):
  - `README.md` — root README (root view of `root_lang`)
  - `docs/{code}/README.md` — docs view for **every** locale (incl. `en`)
  - `docs/i18n.md` — language coverage table + hash footer

## Adding a new skill

1. Create `<name>/SKILL.md` (frontmatter: `name`, `description`).
2. Add `references/` and `examples/` folders as needed (see `repo-i18n/` for a
   complete example).
3. Update `assets/docs/{en,zh,zh-Hant}.json` — add the new folder to the
   `arch_tree` / `stack_tree` / `ack_tree` sections where relevant.
4. Push — CI detects the `DOCS_HASH` change and regenerates all READMEs.

## Adding / updating a language

See [`repo-i18n/references/workflows.md`](../repo-i18n/references/workflows.md).

- New language: copy `assets/bundles/en.json` → `assets/bundles/{code}.json`
  and `assets/docs/en.json` → `assets/docs/{code}.json`, translate, set
  `langCode` to the **full** locale code.
- Variant (`zh-Hant`): copy the base file (`zh.json`) and override only the keys
  that differ; missing keys fall back per the `fallback` tree in
  `assets/.i18n_config/i18n.yml` (default: variant → base → en).
- Change root language: set `root_lang` in `assets/.i18n_config/i18n.yml`.

## Regeneration

- CI recomputes content hashes (`BUNDLES_HASH`, `DOCS_HASH`, `TEMPLATES_HASH`)
  on every push and regenerates only what changed.
- To **force** regeneration without content changes, include `b-doc` in the
  commit message.
- Never edit generated files directly (`README.md`, `docs/*/README.md`,
  `docs/i18n.md`) — CI overwrites them.
