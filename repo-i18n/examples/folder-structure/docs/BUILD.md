# Build Guide

This file is **hand-maintained** (not generated by CI).

## Prerequisites

- Flutter SDK (stable channel)
- Go toolchain (for the CGO bridge)
- Platform toolchains: Android SDK/NDK, Windows (MSVC + Inno Setup), Linux (gcc + deps)

## Build

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
# then build per platform
```

See the CI workflow (`.github/workflows/build.yml`) for the exact steps used in
automated builds.
